# FNP Sales Analysis Dashboard

## Project Overview
An interactive sales analysis dashboard developed using Microsoft Excel to analyze business performance, revenue trends, customer spending, and product performance.

## Tools & Technologies
- Microsoft Excel
- Power Query Editor
- Power Pivot
- DAX & Measures
- PivotTables & PivotCharts
- Data Modelling

## Key Features
- KPI tracking
- Revenue analysis by occasions and categories
- Monthly and hourly revenue trends
- Top 5 products by revenue
- Top 10 cities by orders
- Interactive slicers and timelines

## Key Metrics
- Total Orders: 1,000
- Total Revenue: ₹35,20,984
- Average Order-to-Delivery: 5.53
- Average Customer Spending: ₹3,520.98
